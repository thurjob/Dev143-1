# 🎮 Mario Game (Em Desenvolvimento)

Este é um projeto simples inspirado no clássico **Super Mario**, desenvolvido em **HTML, CSS e JavaScript**.  
O objetivo é recriar uma versão divertida e prática para estudos de programação e desenvolvimento web.

---

## 🚀 Tecnologias Utilizadas

- [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML)
- [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS)
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)

## ⚙️ Como Executar o Projeto

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/Mario-Game.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Mario-Game
   ```

3. Abra o arquivo `index.html` diretamente no navegador.

---

## 🎯 Objetivo do Jogo

- Controlar o Mario
- Pular os obstáculos (canos)
- Evitar a tela de **Game Over**
- Aumentar sua pontuação sobrevivendo o máximo possível

---

## 📌 Funcionalidades Atuais

- Animação do personagem (Mario)
- Obstáculo (cano) em movimento
- Sistema simples de colisão e Game Over
- Fundo animado (nuvens)
